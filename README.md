# RainWatch Prototype

เว็บต้นแบบสำหรับ EL216 Class Activity #2 แสดงแนวคิดระบบตรวจวัดปริมาณฝนด้วยเซนเซอร์บน AMR และหน้าเว็บสรุปข้อมูล

## ใช้งาน

เปิด `index.html` ในเว็บเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้งโปรแกรมหรือเชื่อมต่อเซิร์ฟเวอร์ โดยเก็บ `replay.js` ไว้ในโฟลเดอร์เดียวกัน

ค่าที่เห็นเป็นชุดข้อมูลตัวอย่างสังเคราะห์ในรูปแบบ telemetry ที่ AMR อาจส่งได้ เช่น รหัสอุปกรณ์ พิกัด เวลา ปริมาณฝนสะสม อัตราฝน คุณภาพสัญญาณ และแบตเตอรี่ เลือกสถานีเพื่อดูแพ็กเก็ตและใช้ปุ่มเล่น/หยุด ปรับความเร็ว หรือเลื่อนแถบเวลาเพื่อเล่นข้อมูล 2 ชั่วโมงย้อนหลังให้เร็วขึ้น แผนที่เป็นภาพเชิงแนวคิดและจุดตรวจไม่ใช่พิกัด GPS จริง ไม่มีการแก้ค่าฝนรายสถานี และไม่มีการเชื่อม AMR จริง

## เผยแพร่ด้วย GitHub Pages

1. สร้าง GitHub repository ใหม่และอัปโหลด `index.html`, `replay.js` และ `README.md` ไว้ที่ root ของ repository
2. ใน GitHub เปิด **Settings → Pages**
3. เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/ (root)` แล้วกด **Save**
4. หลัง GitHub Pages เผยแพร่สำเร็จ จะมี URL รูปแบบ `https://<username>.github.io/<repository>/`

เว็บต้นแบบนี้ยังไม่ได้เชื่อมฐานข้อมูล ระบบ GPS หรือ AMR จริง และไม่ใช่ระบบเตือนภัยทางการ
